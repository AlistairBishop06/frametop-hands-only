# Dashboard font and rasterizer

- `InterVariable.ttf`: Inter by the Inter Project Authors, from `rsms/inter` (`docs/font-files/InterVariable.ttf`, Git blob `4ab79e0102bbe0ffa1ed879b13e52ac8c6487833`). See `Inter-LICENSE.txt` for the SIL Open Font License 1.1.
- `stb_truetype.h`: stb truetype by Sean Barrett and contributors, from `nothings/stb` (Git blob `ff5d70ce57a504ee62184b5f13d9f3472561b564`). Its public domain or MIT notice is retained in the header.

The font is bundled in releases so the dashboard uses the same typography on every Frame. The rasterizer is compiled into the dashboard binary.
